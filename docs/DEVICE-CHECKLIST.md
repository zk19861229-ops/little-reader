## 必须通过

- [ ] 安装 APK 并能从桌面打开“小小点读”。
- [ ] 体验页整句、单词、慢速均有声音。
- [ ] 在家长设置试听任意英文，确认英语语音包实际可用。
- [ ] 拍摄实际教材，文字框位置与英文一致；横拍照片不会横倒。
- [ ] 在相册选择照片也能识别。
- [ ] 跨行句子能完整读出；识别错误可由家长修正。
- [ ] 连续快速点两个单词时，旧声音停止，只播放最新选择。
- [ ] 拒绝麦克风后仍能点读；允许后能重新开始录音。
- [ ] 录下孩子声音，再按“听听我读的”听到示范和孩子的声音。
- [ ] 录音过程中切到桌面 / 锁屏，录音停止。
- [ ] 开启飞行模式后，导入新图片识别并朗读（需事先安装离线语音包）。
- [ ] 关闭重开应用，书页和录音仍存在。
- [ ] 删除一页不影响其他书页。
- [ ] 老人不需要指导即可完成打开、拍照、点读流程。
