# 小小点读 · 首版执行章程

## 已确认范围
用户于本轮明确要求实现安卓应用；设备 OPPO Find X，孩子小学一年级，老人陪读。
首版包含拍照 / 导入书页、句子与单词点读、慢速示范、跟读录音回放、最近书页、家长文字修正。
不包含自动评分、账户、社交、广告或付费订阅。

## 架构边界
安卓原生 Kotlin，最低 Android 8.0（API 26），竖屏、大字号、本地私有存储。
原方案为云端 OCR / TTS；已向用户提出本地 OCR 与系统英语语音包选项。
先实现无需配置付费密钥的本地家庭试用版供验收；本轮未收到用户对该选项的明确答复，不记为用户已批准架构变更。
本地实现随 APK 提供，不部署云端服务。若用户要求维持云端方案，应另行配置服务与后端，再替换识别和语音适配器。
不部署付费服务，不把儿童音频发送到外部，不上架商店。

## 验收与里程碑
1. 构建与公共模块：可编译，书页 / 句子模型、缓存、界面完成。
2. 完整端到端：识别一页英文，点整句和单词，切慢速，跟读并交替回放，重启后仍可打开。
3. 质量与交付：单元测试、lint、APK 构建、模拟器关键路径；交付 APK 与安装 / 真机验收说明。
阶段门禁合并为可安装首版交付，由用户在 OPPO 手机上最终验收。

## 假设与风险
- 实际 Android 版本尚未读取；仅承诺 API 26+ 的代码兼容，OPPO 真机仍需验收。
- 系统英语语音包是否可用未知，必须提供缺失提示与设置入口。
- OCR 并非总正确，提供家长纠错；发音评测未实现，不冒充纠音结果。
- 照片与录音留在应用私有目录，关闭系统备份，删除书页同时删除录音。
