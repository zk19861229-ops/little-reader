# 小小点读

给小学一年级孩子和陪读老人使用的安卓绘本点读应用。目标设备为 OPPO Find X，支持 Android 8.0（API 26）及以上的 ARM64 手机。

## 已实现

- 拍摄书页，或通过系统文件选择器导入照片。
- 图片中英文句子的点击框、单独的大号句子按钮、单词点读。
- 正常 / 慢速英文示范，美式 / 英式设置。
- 一键开始、再点结束的跟读录音，最长 15 秒；示范与孩子录音依次播放。
- 最近书页、本地保存、家长修正文字、手动输入英文、删除书页与录音。
- 内置用户提供的“小熊过河”体验页与整句 / 单词声音。

第一版**没有自动发音评分或纠音**。录音回放仅供模仿、对照。

## 安装与第一次使用

1. 将交付的 APK 下载到 OPPO 手机，点开安装。系统提示时，允许当前文件管理器安装此应用。
2. 打开“小小点读”，先打开“小熊过河 · 体验页”，点击“听示范”和“慢一点”。体验页自带音频。
3. 点“跟我读”，允许麦克风权限；再次点击开始录音，读完后点“读完了”。
4. 点“听听我读的”，先听示范，再听刚才的录音。
5. 在首页“家长”入口设置英语声音。任意新书页的朗读需要手机有**离线英语 TTS 引擎与对应口音的语音包**。体验页有声音不代表语音包已安装。
6. 回首页点“拍课本”，拍清楚英文区域，识别完成后点读。

### OPPO 上的语音包

国产系统可能没有预装英语语音引擎。应用不会捆绑或静默安装其他厂商的引擎。
在“家长 → 安装或设置英语语音”中查看文字转语音引擎，选择一个支持离线英语的引擎并下载英语（美国）或英语（英国）语音包。
若该设备没有可用的英语引擎，需要家长先安装来源可信、兼容该系统的语音引擎，再回到应用试听。
不同引擎音质不同；首版优先选该口音下可用的离线声音，不会偷换到另一种口音或联网声音。

## 数据与联网

- 拉丁文字 OCR 模型随 APK 打包，首用无需下载模型，不要求手机安装 Google Play 服务。
- 应用移除了互联网权限；照片、OCR 结果和跟读录音都在应用私有目录。
- 新句子由系统离线英语语音包生成，合成音频保存在缓存中，上限约 60 MB。
- 删除书页会删除对应照片、文字与录音。卸载应用会删除全部内容，已关闭系统备份。
- 无登录、统计 SDK、广告或自动上传。安装语音包由外部系统设置 / 语音引擎自行处理。

## 开发

- Kotlin 2.0.21 / Android Gradle Plugin 8.7.3 / Gradle 8.9 / JDK 17。
- compileSdk 35 / targetSdk 34 / minSdk 26。
- 本版本是家庭侧载试用版，暂不满足未来应用商店的上架与签名管理要求。

安装 Android SDK（platforms;android-35、build-tools;34.0.0、platform-tools）与 JDK 17，在 `local.properties` 配置 `sdk.dir` 后运行：

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
./gradlew connectedDebugAndroidTest
```

第二条命令需要已启动的模拟器或通过 USB 授权的安卓设备。构建产物：`app/build/outputs/apk/debug/app-debug.apk`。
debug APK 使用开发签名；后续家庭更新请保留同一份开发签名，否则需要卸载旧版，导致本地数据丢失。

## 代码布局

| 文件 | 职责 |
| --- | --- |
| MainActivity.kt | 首页、点读、家长设置、权限与导入流程 |
| BookRecognizer.kt | 本地 OCR，超时与资源释放 |
| ReadingPage.kt | 句子、位置和跨行合并 |
| PageImageView.kt | 图片缩放与点击框 |
| PhotoLoader.kt | 照片降采样、EXIF 旋转校正 |
| SpeechController.kt | 离线英语声音选择、缓存、播放、音频焦点 |
| PracticeRecorder.kt | 短录音、临时文件与成功后替换 |
| PageStore.kt | 原子保存、读取、删除 |
